# AIS Service Video Generation

Creates AIS Service asynchronous video generation tasks through New API.

## Channel setup

Choose the Task Plugin (61) channel type and bind `AIS Service Video Generations`. Get the Base URL and key from the AIS Service gateway console.

If the upstream is another New API gateway, choose the New API (60) channel type and enter that gateway's address and token. The upstream gateway also needs this plugin installed.
